## 무엇을 바꿨나요?

- **정산 요약서:** 지원실 담당자의 개별 파일 확인·수기 취합 문제를 파악하고 요약 파일을 제공했습니다. 이 예제는 기존 발행액 재사용, 잘못된 합계 차단, 계약 종료·자료 없음·0원 처리의 핵심을 담았습니다. 엑셀 생성·서식과 DB 조회는 생략했습니다.
- **중복 집계:** 매출 한 건이 여러 설정 행과 연결돼 복제되고, 앱 구분 조건 누락으로 다른 앱의 매출까지 섞이는 문제를 수정했습니다. 가상 데이터로 두 원인을 각각 고쳤을 때의 한계와 함께 고쳤을 때의 결과를 비교합니다.
- **AGDD:** 개발 흐름을 단계별 스킬로 구성해 어드민 개발에 시범 적용 중입니다. 이 예제는 원문 버전 변경, 완료 조건 누락, 끊긴 검증 연결, 미답 질문을 검사하는 원리만 담았습니다. 문서 파싱·CI·전체 스킬은 생략했고, 검사 통과가 설계의 타당성이나 실제 테스트 성공을 뜻하지는 않습니다.

## 실행

Node.js 22.23 이상과 Python 3을 사용합니다. 별도 패키지 설치는 필요하지 않습니다.

```bash
npm test
```

이 저장소의 예제 테스트 **19개 통과**: 정산 요약 8개, 조인 재현 4개, 명세 검사 7개. 이는 예제에 대한 검증 결과입니다.
